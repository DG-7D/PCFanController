# PCファン制御器

PC用のファンを風量の調節ができる扇風機として使うための基板です。

## 操作

上から
- 表示ボタン: 回転数表示と指令値表示の切替
- +ボタン: 指令値増加、電源断に押すと始動
- -ボタン: 指令値減少、0%のとき押すと電源断

## 解説

### 電源

電源の12 VをUSB Power Deliveryで得ています。

### 回転数測定

PC用のファンは1回転につき2回パルスを出す形で回転数を出力しています。通常マザーボードなどでは一定時間のパルス数から回転数を計算していますが、この制御器ではパルスが来るたびにパルスの間隔から回転数を計算して表示するため、より低遅延で表示を更新できます。応答性を確保しつつ値がちらつかないようにするフィルタも実装しています。

### PWM指令、電源スイッチ

PC用のファンは、マザーボード側からPWM信号で回転数を指令することができます。また、0%でも停止しないファンも多いため、0%指令とは別に電源を遮断できるようにしています。

### 表示

4桁7セグメントLEDをシフトレジスタで駆動しています。7セグが少し浮いていることを利用し、シフトレジスタを7セグの下に滑り込ませています ~~(McbeEringiさんのパクり)~~。

### 製造

基板はJLCPCBに発注しています。部品の実装は手で行っています。チップ抵抗やコンデンサは1608サイズで、手先が器用でなくても頑張ればギリギリはんだ付けできます。
