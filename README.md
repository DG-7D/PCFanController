# PCファン制御器

PC用のファンを風量の調節ができる扇風機として使うための基板です。

## 機能

- USB PDから12 V要求しファンに給電
- 回転数の低遅延表示
- PWM指令値の調整
- ファン電源のON/OFF

## 操作

- 4ピンPCファン、12V出力対応のUSB PD電源を接続
- 始動時は停止状態、+を押すと30%で始動

| ボタン | 操作 |
| ----: | :---- |
| DISP | 表示切替 (回転数表示→指令値表示→消灯→(ループ)) |
| + | 指令値増加、停止時に押すと始動 |
| - | 指令値減少、0%のとき押すと停止 |

## 技術解説

### 電源

電源の12 VをUSB Power Deliveryで得ています。秋月電子でも販売されているIC、CH221Kを使うと簡単にPDから電源を得ることができます。

### 回転数測定

PC用の3ピン、4ピンファンは、1回転に2回パルスを出す形で回転数を出力しています。通常のマザーボードなどは、一定時間(1秒など)ごとのパルス数を数えて回転数を表示しているため、表示は一定時間ごとにしか更新されません。一方、この制御器では、パルスが来るたびに前回のパルスとの間隔から回転数を計算して表示するため、変化を低遅延で表示することができます。

マイコン(ATtiny404)のタイマには周波数測定に特化した機能も存在しますが、想定されている周波数が高すぎる(計れる時間が短すぎる)ため、今回の用途には使えませんでした。ここでは、タイマを単なる一定周期(25 kHz)の割り込みとして使用し、ソフトウェアで遅いカウンタを作っています。そのうえで、パルス入力端子の割り込みのタイミングでカウンタの値を読み出し、パルスの間隔を取得しています。

また、出力されるパルスの間隔には多少の揺らぎがありますが、これを馬鹿正直に表示に反映すると数字がちらついて読めなくなります。そこで、前回値から一定の範囲内の数値の変動は無視するようにしてあります。ローパスフィルタではないので応答が遅くなることはなく、一定を超える変動は即座に反映されます。

また、展示に使用しているファン特有の問題として、たまにパルスを拾い損ねることがあります。何も対策しないと間隔が広くなり回転数が「0」と一瞬表示されてしまうため、一定時間は「0」を無視して直前の回転数を表示するようにしています。それでも低速回転時はそこそこの頻度で「0」になります。

### PWM指令、電源スイッチ

PC用の4ピンファンは、マザーボード側からPWMで回転数を指令することができます。ここでいうPWMは、最大回転数に対する望ましい割合をファン側の制御器に指令するためのものであり、擬似的なアナログ電圧の出力を目的とするPWMとは異なります。PWM出力に使用するタイマは先述の定期割り込みと同じタイマを使用しており、また、規格上このPWMは25 kHzとなっています。先述のカウンタが25 kHzだったのはこのためです。

指令値30%以上では線形に変化するよう求められていますが、30%未満での挙動はファンにより異なり、0%でも停止しないファンも多いため、0%指令とは別に電源を遮断できるようにしています。

なお、これを電源側ではなくGND側のスイッチングで実装してしまったため、オフ時に意図しない経路で電流が流れてしまう状態になってしまっています。3番ピンにダイオードが入っているのはこれの応急処置です。

### 表示

表示に使用しているのは4桁の7セグメントLEDで、アノードがセグメントごとに8本、カソードが桁ごとに4本の端子があります。異なる桁に異なる数字を同時に表示することはできないため、表示する桁を高速に切り替えながら表示しています。この間隔の制御にも先述のカウンタを流用しています。全桁のリフレッシュレートは25k/64/4≅98 Hzに設定してあり、ほとんどちらつきのない表示となっています。

また、12本すべてマイコンの端子に接続するのは現実的でないため、シフトレジスタ(74HC595)を使用しています。シフトレジスタを2つ直列にし、桁選択も任せることでマイコンからの端子は3本(データ、クロック、ラッチ)で済んでいます。制御にSPI機能を用いたため、使わない受信端子が無駄に1本空いていますが……。

また、7セグが少し浮いていることとシフトレジスタの背が低いことを利用し、シフトレジスタを7セグの下に滑り込ませています ~~(McbeEringiさんのパクり)~~。

シフトレジスタには出力の有効無効を制御できるピンもあり、ここにPWM信号を入力することで表示の明るさを制御できるようにもなっています。先述の電源スイッチの信号も実はシフトレジスタから出していて、こちらがPWMになっては困るため、片方のみこれを行っています。

## 製造

基板はJLCPCBに発注しています。無料の基板CADであるKiCadを使用して設計し、データを送信するだけで、数百円で基板を作ってもらうことができます。

部品の実装は手で行っています。チップ抵抗やコンデンサは1608サイズで、手先が器用でなくても頑張ればギリギリはんだ付けできます。
