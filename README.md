# PCファン制御器

## 機能

- USB PDから12 V要求しファンに給電
- 回転数の低遅延表示
- PWM指令値の調整
- ファン電源のON/OFF

## 操作

- 4ピンPCファン、12V出力対応のUSB PD電源を接続
- 始動時は停止状態、+を押すと30%で始動

| ボタン | 操作 |
| ----: | :---- |
| DISP | 表示切替 (回転数表示→指令値表示→消灯→(ループ)) |
| + | 指令値増加、停止時に押すと始動 |
| - | 指令値減少、0%のとき押すと停止 |

## PCファンの動作

4ピンのPCファンの場合、PCやこの制御器が指令するのは最大回転数に対する割合であり、PWMのデューティー比の形で送信され、回転数の制御はファン側で行われる。30%以上ではおおむね線形に変化するようにファン側で制御される。30%未満での挙動はファンにより異なり、最低の回転数を維持するものが多く、0%では停止したりしなかったりする。

0%で停止しないファンであっても、この制御器の停止状態では通電自体を切るので停止する。
