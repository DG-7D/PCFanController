# PCファン制御器 ATtiny404 ファームウェア

## 書込

右上テストパッド(スルーホール)の上側を使用、左からUPDI, GND, 3.3 V

ヒューズ設定 (デフォルト、16MHz)

```
pio run -t fuses
```

書込

```
pio run -t upload
```

## ピン

### ATtiny404

- 操作入力 (プルアップ)
    - PA7: 表示ボタン
    - PA6: +ボタン
    - PA5: -ボタン
- シフトレジスタ出力
    - PA1: データ
    - PA3: クロック
    - PA4: ラッチ
    - PB3: 有効 (Active Low)
- ファン
    - PB0: 回転数パルス入力 (オープンコレクタ)
    - PB1: PWM出力 (MOSFET反転)
- その他
    - PA0: UPDI (/RESET)
    - PA2: SPI MISO (未使用)
    - PB2: UART TxD

| 説明 | ピン | ピン | 説明 |
|----:|:----|----:|:----|
| 3.3 V | VDD | GND | GND |
| 595ラッチ← | PA4 | PA3 | →595クロック |
| /-ボタン→ | PA5 | PA2 | (←SPI MISO) |
| /+ボタン→ | PA6 | PA1 | →595データ |
| /表示ボタン→ | PA7 | PA0 | UPDI |
| /595有効← | PB3 | PB0 | ←/ファン回転数パルス |
| UART← | PB2 | PB1 | →/ファンPWM |
